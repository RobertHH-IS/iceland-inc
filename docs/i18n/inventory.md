# Icelandic translation: inventory of user-facing text

Status: working document for the Icelandic translation (September 2026). Companion files: [glossary.md](glossary.md) (terminology) and [architecture.md](architecture.md) (how the translation plugs into the code).

## How this was counted

- **Model texts** were read from the model definitions as the registry builds them (`src/models/index.ts`, which adds the concept library as a module). A scratch script walked every module of each model and recorded each translatable field, with its entity id. "Instances" counts every entity, including those generated by rule families. "Unique" counts distinct English strings, which is what a translator actually writes. Words are whitespace-separated tokens. Placeholders such as `{tau0%}` count as one word.
- **UI strings** were found by scanning `src/ui/**` for JSX text, `aria-label` and `title` attributes, and string or template literals. The candidates were then curated by hand into one message key per string. The curated list includes the strings that `src/core` hands to the interface, such as posting descriptions and accounting-check labels. The full key list is in [Appendix A](#appendix-a-ui-message-keys).
- **Regime strings** are returned by `regime()` functions, so they cannot be read from data. They were found by reading the model source.
- This document covers what is committed on 28 September 2026. The recalibration to current Statistics Iceland data runs in parallel and will change some English texts, mostly provenance notes and descriptions that contain numbers (see [§6.4](#64-texts-that-contain-data)).

Findings that matter for the translation:

1. **Labels are used as keys in five places.** A translated label would silently break each of them:
   - `leverSections` uses the section title as the section id, and `GROUP_ORDER = ['Policy', 'Economy', 'World']` compares English group names;
   - `chartTabs` uses the indicator group as the tab id;
   - `PLAYER_CARDS` and `GROUP_NOUNS` fall back to the group **label**, and the reference model's groups are free labels such as `'Households'`;
   - the regime-badge logic compares regime strings with the baseline's;
   - the Iceland mortgage module's own test (`src/models/iceland/modules/mortgages.ts`) compares regime strings (`x.regime === 'Debt-service cap binds'`).

   The rule: translate at display time only, and keep ids in English.
2. **Display strings are parsed as data.** `unitKind`, `fmtIndicator`, `shortUnit` and `fractionTail` parse unit strings such as `fraction of deposits`, `% vs baseline` and `pp of GDP`. Units must stay English in the definitions and be mapped to Icelandic when shown.
3. **The kernel builds English sentences.** Examples are `describePosting`, `"Set from outside the model by the lever(s): …"`, `"Shown as deviation-pct (% vs baseline)."`, the leg labels `"A → B"` in flow influences, and feed messages. The stabiliser feed also formats its numbers with a decimal point (`feedNumber`). These need ids and numbers in place of finished sentences (see architecture §4).
4. **Raw ids reach the screen**, in English too:
   - `describePosting` prints the instrument **id** ("A new claim (mortgagesN)");
   - the inspector prints `c.school.replace('-', ' ')`, `pipe.kind.toUpperCase()` and `{flow.account} account`;
   - the breadcrumbs print `s.kind`;
   - `CategoryChip` prints the raw category.

   Each needs a message key.
5. **Sentences are assembled from fragments**, for example `Balance sheet` + `' of all its players'`, the card labels built from `m1 v1 + ', set by the rule'`, and `"{n} month{s}"`. Icelandic word order and inflection need whole-sentence messages with parameters and real plural rules. Icelandic plurals differ from English: 21 is singular ("21 mánuður").
6. **The map's layout depends on label length** (`maxChars`, `tabWidth`, `labelWidth`, the 14-character metric truncation). Icelandic labels run longer: "Útflutningsfyrirtæki" has 20 characters where "Exporters" has 9. Layout must be computed from the localized labels, and every player needs an Icelandic `short`.

## 6. Special cases the translation must handle

### 6.1 Placeholders
- 250 of the Iceland model's 374 rule explanations (`explain.rule`) contain 489 `{param}`, `{param%}` or `{param pp}` placeholders, filled from live parameter values. The reference model has 24 rules with 44 placeholders. Icelandic text must keep the same placeholder set, and a test should check this (architecture §6).
- 35 Iceland placeholders (7 in the reference model) name a parameter missing from the rule's `params`. Almost all are adjustment speeds such as `{lamC}`, which `Influence.params` includes anyway. Two are in neither list: `{kapT}` in `capitalRatio` and `{muX}` in `importsExporters`. The kernel fills them from the full parameter table, so a UI-side filler needs that table (architecture K4). The inspector's parameter list also omits these two.
- **Bug, in English as well:** `taxRate.explain.what` contains `{tau0%}`. The kernel fills only `explain.rule`, so the inspector shows "At {tau0%} it also stands in for…" literally.
- The stabiliser feed templates use `{value}` and `{change}`, and the kernel fills them with a decimal point (`feedNumber`).

### 6.2 Rule families and generated labels
Rule families build their texts from name tables in `src/models/iceland/util.ts` and in the modules, such as `AGE_LABEL`, `FIRM_NAME`, `DEP_LABEL` and `WHO`. For example, `Deposit interest to ${DEP_LABEL[pl]}` and `New mortgages to the ${who} this year.` give 374 variable labels from a few dozen templates. Icelandic needs the names in different grammatical cases ("til ungra heimila" in the genitive, "hjá ungum heimilum" in the dative). Translating per instance avoids grammar templating but means about 2,650 entries. Translating per template needs a declension table. Architecture §3.3 recommends per-instance keys filled by per-family template functions with a case table.

### 6.3 Regime strings
Regime strings are returned by functions (`regime: (c) => … 'Debt-service cap binds' …`), so they cannot be enumerated from data, and a module test in `mortgages.ts` compares one of them. They need a declared list per rule, so that they can be extracted, translated and checked (architecture §4, K2).

### 6.4 Texts that contain data
310 Iceland texts contain literal numbers other than ages, years and rule numbers:
- 117 provenance notes;
- 108 rule explanations;
- 25 lever definitions;
- 15 parameter descriptions;
- the rest are descriptions of players and instruments, for example "about 13% of GDP" for tourism and "About 65% of Icelandic mortgages".

The model's description also says "Calibrated to 2025 data". Recalibrating to current Statistics Iceland values will change these English strings, and every Icelandic copy then goes stale. Numbers that come from data should become `{param}` placeholders, or be removed from prose. A staleness check (architecture §6) must flag translations whose English source has changed.

### 6.5 Inline Icelandic and names
- Keep proper names as they are: Landsbankinn, Lánamál ríkisins, the Althingi (Alþingi in Icelandic), the Central Bank (Seðlabanki Íslands), Statistics Iceland (Hagstofa Íslands) and the rules "Rules 1300/2025" ("reglur nr. 1300/2025").
- "Króna" is already Icelandic, but its inflection must follow Icelandic grammar: krónan, krónunni, krónunnar, krónur.
